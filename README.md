# TheBookmarker_WebExtension
A web extension that can save bookmarks on web pages.

It allows you to select text, and create a bookmark. The extension will save the bookmark, and when you click on your bookmark, it takes you back to the spot on the page where you left off.

This is a passion project, designed mostly for my personal use when reading "How to Learn to Code and Get a Developer Job" by Quincy Larson online.
